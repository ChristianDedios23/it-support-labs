# Windows Account Administration and Access Control Lab

## Overview

Configured a Windows 11 virtual environment to practice user administration
and secure department-folder access. Created user accounts and a security
group, configured NTFS permissions, and verified access using authorized
and unauthorized accounts.

## Skills Demonstrated

- Windows user and group administration
- Group-based access control
- NTFS permissions and inheritance management
- Access verification across multiple accounts
- Technical documentation and support ticket reporting

## Results

- Granted Accounting group members permission to read, edit, and manage
  department files.
- Verified that Alice could open, edit, and save the test document.
- Confirmed that Charlie, outside the Accounting group, could not access
  the folder.
- Preserved administrator and SYSTEM access.
- Documented configuration changes and test results with screenshots.
